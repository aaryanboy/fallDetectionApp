# Fall Detection App

A React Native application for detecting falls using device sensors.

## About

This mobile application uses accelerometer and gyroscope sensors to detect potential falls and alert emergency contacts.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Expo Go app on your mobile device

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aaryanboy/fallDetectionApp.git
   cd fallDetectionApp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Scan the QR code with Expo Go app on your phone

## Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Start Expo development server |
| `npm run android` | Run on Android device/emulator |
| `npm run ios` | Run on iOS simulator |
| `npm run web` | Run in web browser |
